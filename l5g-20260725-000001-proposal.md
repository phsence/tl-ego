## 1. Verified Root Cause (from live code review)

The candidate generation path is healthy:
- `modify_suppression_rule` is ranked #1 by `rank_affordances()`
- 8 affordances present, counterfactuals injected
- `_candidate_pool_adjustment` applies +0.30 boost to top counterfactual

The failure is downstream: **affordance scores never bias the seed pool**.

Current seed flow:
```
rank_affordances()  →  affordances sorted by jepa_score
_pending_type_reward →  injects 1-5 neurons of counterfactual_target_type
seeds = last_seeds + random.sample + NEWBORN_GUARANTEE + integrator_floor + conc_recovery
run_resting_kwta(seeds)   ← ignores jepa_score entirely
action_heater            ← rewrites activation_path neurons ignoring affordance ranking
```

Three layers are misaligned:
1. **Seed layer**: random replacement + hard type guarantees drown the 1-5 neuron type-reward
2. **KWTA layer**: `inhibition_strength=0.5`, `top_k=60`, `n_rounds=8` cannot separate near-tie top-2 when concentration is already low
3. **Activation-path layer**: `action_heater` replaces defense→action every tick when `_integration_pressure=False`, destroying counterfactual paths even when they are the top-ranked affordance

## 2. Fix Design (Three Layers, One Direction)

### 2.1 Seed-layer: Affordance-Aware Type Quota

**Location**: `_resting_tick_impl`, after `_pending_type_reward` consumption (line ~8310), before `integrator_floor` (line ~8430).

**Logic**:
```python
_top_aff = observation.get("affordances", [{}])[0]
if _top_aff.get("_cf_injected") and float(_top_aff.get("jepa_score", 0.0) or 0.0) >= 2.0:
    _cf_target = _top_aff.get("counterfactual_target_type") or "integrator"
    _cf_quota = min(8, max(3, DIVERSITY_N // 2))   # 3-8 seeds
    _target_typed = [nid for nid, nt in NEURON_TYPE.items() if nt == _cf_target]
    _replaceable = [i for i, s in enumerate(seeds)
                    if parse_type(s) != _cf_target
                    and i not in getattr(seeds, '_newborn_positions', set())]
    if _target_typed and _replaceable and len(_replaceable) >= _cf_quota:
        _idxs = random.sample(_replaceable, _cf_quota)
        for _idx in _idxs:
            seeds[_idx] = random.choice(_target_typed)
        seeds._integrator_floor_positions |= set(_idxs)   # protect from later bias clobber
```

**Coordination with existing guards**:
- `_cf_active=True` already skips `integrator_floor` and `conc_recovery`, so quota is not overwritten
- `NEWBORN_GUARANTEE` still injects 1-2 action+integrator seeds; quota replaces from `_replaceable` (excludes newborn positions)

### 2.2 KWTA-layer: Concentration-Aware Parameters

**Location**: `run_resting_kwta` (line ~6170), before `AttractorNetwork` construction.

**Logic**:
```python
_prev_conc = RESTING_STATE.get("last_concentration", 0.5)
_stag = RESTING_STATE.get("stagnation_streak", 0)
_inhibition = 0.65 if (_prev_conc < 0.40 or _stag >= 2) else 0.5
_prop_rounds = 12 if (_prev_conc < 0.40 or _stag >= 2) else n_rounds
_top_k_dyn = max(30, min(60, int(_n_active * 2.0))) if (_prev_conc < 0.40 or _stag >= 2) else top_k

attractor = ng.AttractorNetwork(
    propagation_rounds=_prop_rounds,
    top_k=_top_k_dyn,
    inhibition_strength=_inhibition,
    leak=0.3
)
```

**Why**:
- Higher inhibition + smaller top_k forces winner margin
- More propagation rounds gives newborn/rule_modification boosted edges time to compete

**Why**:
- Current behavior: heater runs every non-integration-pressure tick, destroying counterfactual paths
- Guard: single tick skip is safe because integrator_push branch (when `_integration_pressure=True`) still runs and actively promotes integrator
